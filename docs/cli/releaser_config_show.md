## releaser config show

Show currently used configuration data structure

### Synopsis

Show the currently used configuration data structure for releaser in the current path

```
releaser config show [flags]
```

### Options

```
  -h, --help        help for show
      --only-yaml   Only print the YAML output of the configuration
```
