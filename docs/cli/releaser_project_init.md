## releaser project init

Initialize a new releaser project in the current directory

### Synopsis


Initialize a new releaser project in the current directory with a default config file under .releaser/


```
releaser project init [flags]
```

### Options

```
  -g, --git-executable string   Git executable (default "git")
  -h, --help                    help for init
  -y, --yes                     Automatically answer prompt questions with 'yes'
```
