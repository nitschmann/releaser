## releaser release latest-tag

Print latest git tag

### Synopsis

Print the latest available git tag in this project

```
releaser release latest-tag [flags]
```

### Options

```
  -g, --git-executable string   Git executable (default "git")
  -h, --help                    help for latest-tag
```
