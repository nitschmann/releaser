## releaser commit

Create new commit

### Synopsis

Create a new commit with the given message based on the current configuration

```
releaser commit [MESSAGE] [flags]
```

### Options

```
  -g, --git-executable string   Git executable (default "git")
  -h, --help                    help for commit
  -m, --message                 Print only the message of the new commit
  -t, --type string             Specify explicit type
```
